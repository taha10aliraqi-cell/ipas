# 🚀 MyJop — نظام إدارة المحتوى وخطة عمل صانع المحتوى
### خاص بـ: **طه سعد** وفريقه **«المنافس تيم»** (Instagram & TikTok)

نظام متكامل لإدارة خطة محتوى الشهر الأول والمشاريع البرمجية، مبني بأحدث تقنيات **React Native (Expo)** و **TypeScript** مع واجهة متطورة مصممة خصيصاً للهواتف الذكية ومتصفحات الويب، مع خادم قاعدة بيانات سحابي مستقل تماماً على **Supabase**.

---

## 🌟 مميزات النظام

1. **خطة الشهر الأول الكاملة (4 أسابيع / 12 منشوراً)**:
   - **الأسبوع الأول — صناعة الفضول**: التعريف بفريق المنافس، البرمجة الحديثة، والباكلة بالدهن والبرياني.
   - **الأسبوع الثاني — إثبات خبرة**: أخطاء البرمجة التقليدية، بناء مشروع كامل بالذكاء الاصطناعي، ومقارنة "قبل وبعد".
   - **الأسبوع الثالث — بناء الثقة**: هل تحتاج شهادة لتصبح مبرمجاً؟، ما يميز دوراتنا، ويوم من كواليس الفريق (مع موطة مصطفى).
   - **الأسبوع الرابع — تحويل المتابع إلى مهتم**: تحدي برمجي للمتابعين، من الصفر إلى أول مشروع، واختيار الجمهور لنظام برمجياتهم.

2. **شاشة التلقين التفاعلية (Teleprompter)**:
   - نافذة مخصصة للتصوير المباشر لريلز وإنستغرام وتيك توك مع تحكم بسرعة التمرير التلقائي وحجم الخط، مما يسهل على طه سعد قراءة الهوك والسكربت كاملاً أثناء التصوير.

3. **لوحة كانبان للإنتاج (Production Kanban)**:
   - متابعة مراحل إنتاج كل فيديو: **مخطط له 📝 ⬅️ جاري التصوير 🎬 ⬅️ في المونتاج ✂️ ⬅️ جاهز للنشر 🚀 ⬅️ تم النشر ✅**.

4. **لوحة التحليلات وقمع التفاعل (Content Funnel & Analytics)**:
   - إحصائيات وصول ومتابعين مستهدفين لكل أسبوع ونسب التحويل من مشاهد إلى مهتم ومشترك في دورات ومشاريع الفريق.

5. **فريق العمل ومصطفى ميتر (Mustafa Meter)**:
   - بطاقات أعضاء الفريق (طه سعد، مصطفى، ومهندس المونتاج والأنظمة).
   - عدّاد تفاعلي لموطة مصطفى ووجبات الباكلة بالدهن مع بنك الأفكار السريعة.

## 📱 طريقة تشغيل التطبيق على الهاتف عبر Expo Go

1. افتح موجه الأوامر داخل مجلد المشروع:
   ```bash
   cd c:\MyJop
   ```
2. شغّل خادم التطوير مع ميزة التوصيل النفقي (Tunnel) ليعمل على أي شبكة هاتف:
   ```bash
   npx expo start --tunnel
   ```
   *(أو `npx expo start` إذا كان هاتفك والكمبيوتر على نفس شبكة الـ Wi-Fi)*.
3. افتح تطبيق **Expo Go** على هاتفك (متوفر على App Store و Google Play):
   - **أندرويد**: امسح رمز الـ QR الظاهر في الـ Terminal.
   - **آيفون**: امسح الـ QR عبر تطبيق الكاميرا وسيفتح في Expo Go تلقائياً.
